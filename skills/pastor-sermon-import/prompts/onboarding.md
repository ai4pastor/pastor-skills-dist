# Onboarding Prompt

목표: 목사님 컴퓨터와 Obsidian vault 구조에 맞는 `pastor-sermon-import` 설정을 만든다.

## 진행 원칙

- 한 번에 한 질문만 한다.
- 답을 받으면 임시 설정에 기록한다.
- 모르면 선택지를 제시한다. 기본값이 있으면 기본값을 먼저 권한다.
- 목사님 볼트의 폴더 구조를 먼저 훑어보고, 후보 경로를 찾아 제안한다. 빈칸을 타이핑하게 두지 않는다.
- 실제 파일 쓰기 전 설정 미리보기를 보여준다.
- 목사님이 승인하면 설정 파일을 생성한다.
- 저장 경로는 `python3 scripts/paths.py` 가 알려주는 값을 쓴다.

## 질문 순서

1. Obsidian vault 폴더 경로가 어디인가요?
2. 설교 원본 파일들이 들어 있는 폴더는 어디인가요?
3. 메인 설교 노트는 vault 안 어느 폴더에 저장할까요?
4. 설교 조각 노트는 vault 안 어느 폴더에 저장할까요?
5. 기존 설교 노트 예시 파일이 있나요? 있으면 경로를 알려 주세요. (파일명 규칙·frontmatter 파악용)

### 6. 분류 체계(WORD)를 쓰시겠습니까?

세 가지 중 하나를 골라 주세요.

**(1) 강의 표준 프리셋을 쓴다** — 가장 빠릅니다
목회자용으로 정리된 WORD 분류표를 그대로 씁니다. (`data/word_preset.a4p.json`)

- World(지식 영역) 대분류 9개 · 소분류 69개
- Outcome(활용 목적) 9개 · Route(진행 단계) 4개
- Doctrine(신학 주제) 179개 — 성경학·조직신학·실천신학·영성·삶·절기 6개 묶음

설교 노트에 실제로 쓰이는 값은 이 중 일부(설교 관련 World 5개 · Outcome `🏷️ 설교` ·
Route `📝완료` · Doctrine 3~6개)이고, 나머지는 목록으로만 들고 있습니다.
목록에 없는 값은 스킬이 절대 새로 만들지 않습니다.

**(2) 목사님이 이미 쓰는 분류 목록이 있다** — 그 노트를 읽어 오겠습니다
분류값을 정리해 둔 노트가 있으면 경로를 알려 주세요. 제가 읽어서 목록으로 만들고,
미리보기로 확인받은 뒤에만 저장합니다. **노트를 고치지는 않습니다.**

**(3) 분류를 쓰지 않는다** — 이후 분류 질문을 모두 건너뜁니다
성경구절 링크와 조각 분해는 그대로 동작합니다. 나중에 언제든 켤 수 있습니다.

### 7-A. (6번에서 **(1) 프리셋**을 고르셨을 때)

7-1. 설교 노트에 붙일 World 값을 골라 주세요. 여러 개 고르실 수 있습니다.
- `📩 201 청소년부 설교` · `📩 202 어린이부 설교` · `📩 203 대예배 설교`
- `📩 205 사역 참고자료 & 소재` · `📩 107 교리문답 & 신조`

(전체 69개 목록을 보시겠습니까?)

7-2. 설교 조각 노트에 공통으로 붙일 World 값은 `📩 206 설교 조각 & 영감`으로 하겠습니다.
조각에는 Outcome·Route를 붙이지 않는 것이 표준입니다. 이대로 하시겠습니까?
→ `classification.fragment_world`

7-3. Doctrine 179개를 전부 허용 목록에 넣겠습니다. 스킬은 이 안에서만 고르고,
목록에 없는 값은 만들지 않습니다. `🔖하나님`·`🔖청소년사역`은 너무 넓어서
**사용을 지양**하도록 표시해 두겠습니다.
(일부만 쓰시겠다면 6개 묶음 중 원하는 것만 고르실 수 있습니다.)

7-4. Route는 값을 하나만 쓰는 방식(`route: "[[📝완료]]"`)입니다.
여러 개를 넣으면 스킬이 오류로 잡습니다. 이대로 하시겠습니까?
→ `classification.route_scalar: true`

7-5. 분류값을 노트에 `[[📩 201 청소년부 설교]]`처럼 **링크로** 넣으시겠습니까?
링크로 넣으면 옵시디언 그래프에서 분류별로 모아 볼 수 있습니다. (권장)
→ `classification.wrap_values_in_wikilink: true`

7-6. 설교 원고 한 편에 World를 하나만 붙이도록 검사할까요? (권장)
→ `classification.single_world: true`

### 7-B. (6번에서 **(2) 내 목록**을 고르셨을 때)

7-1. 분류 목록 노트 경로를 알려 주세요.

```bash
python3 scripts/parse_word_source.py "{노트 경로}"
```

7-2. (읽은 뒤) 다음과 같이 인식했습니다 — 맞습니까?
World 소분류 {N}개 · World 대분류 {M}개 · Outcome {O}개 · Route {R}개 · Doctrine {D}개
(각 축 앞 5개 값 미리보기)

7-3. 인식하지 못한 축이 있으면, 그 축의 값들이 노트에서 어떤 모양으로 적혀 있는지
알려 주세요. 스킬이 찾는 모양은 아래와 같습니다.

| 축 | 모양 |
|---|---|
| World 소분류 | `[[📩 201 청소년부 설교]]` |
| World 대분류 | `[[📖 200 설교 & 사역]]` |
| Outcome | `[[🏷️ 설교]]` |
| Route | `[[📝완료]]` |
| Doctrine | `[[🔖칭의]]` |

접두어가 다르면 `--prefix world=🌍` 처럼 알려 주시면 됩니다.
접두어를 아예 쓰지 않으시면 `--generic` 으로 읽습니다.
자세한 계약은 `python3 scripts/parse_word_source.py --explain`.

7-4. 이후 7-A의 7-4~7-6(Route 단일값·링크 표기·World 1개 검사)을 같은 방식으로 묻습니다.

### 8~12

8. 성경구절 노트가 이미 있나요? 있다면 어느 폴더인가요?
   (알려 주시면 링크가 빨간색으로 남는 구절이 몇 개인지 검증 단계에서 함께 보고합니다.)
9. 성경구절 wikilink 형식은 기본값이 `[[요3_16]]` (강의 공통 표준)입니다. 이대로 쓸까요?
   바꾸려면 `{normalized}`가 들어간 형식으로 알려 주세요.
10. 설교 파일명에 **대상 표시**를 쓰시나요? (예: `260111_청_제목.docx` 의 `청`)
    - 쓰신다면 쓰는 표시를 모두 알려 주세요 (예: `청`, `어`, `대`) → `naming.target_markers`
    - 폴더 이름으로 대상을 구분하신다면 폴더→표시 대응도 알려 주세요
      (예: `청소년부`→`청`) → `naming.folder_to_target`
    - **안 쓰신다면 비워 둡니다.** 비워 두는 것이 안전합니다 — 대상 표시를 쓰지 않는
      파일명에서 제목 첫 단어를 대상으로 잘못 읽는 일이 없습니다.
11. 메인 노트와 조각 노트의 파일명 규칙은 어떻게 할까요?
    - 기본값: 메인 `{date}_{title}_{main_passage}.md`, 조각 `{sermon_id}_{title}.md`
    - 쓸 수 있는 값: `{date}`(2026-01-11) `{yymmdd}`(260111) `{target}` `{title}`
      `{main_passage}` `{sermon_id}` `{index}`
    - 강사 표준 형식: 메인 `{yymmdd}_{target}_{title}_{main_passage}.md`
    - **조각을 나중에 재사용·병합하시려면 조각은 `{title}.md`로 두셔야 합니다.**
      파일명이 제목과 같아야 같은 조각을 다시 찾을 수 있습니다.
12. 이미 같은 이름의 노트가 있을 때 어떻게 할까요?
    - 메인 설교 노트: 기본 `ask`(멈추고 물어보기), `skip`(건너뛰기)
    - 설교 조각 노트: → `naming.fragment_collision_policy`
      - `skip` (기본) — 기존 조각은 손대지 않고, 메인 노트의 링크만 그 조각으로 연결합니다.
        새 글머리는 보고에만 남습니다. 가장 보수적입니다.
      - `merge` — 기존 조각 **끝에 새 글머리만 추가**합니다. frontmatter(분류·날짜)는
        그대로 두고, 중복 글머리는 넣지 않습니다. 설교를 임포트할수록 조각이 자랍니다.
      - `ask` — 병합 대상을 보여주고 그때 물어봅니다.

## 마지막 출력

설정 미리보기를 JSON 형태로 보여주고 다음 질문을 한다.

```text
이 설정으로 저장할까요? 저장하려면 "OK 저장"이라고 답해 주세요.
```

저장 후 `python3 scripts/config_loader.py "{config}"`로 유효성을 확인하고,
설교 샘플 1개로 dry-run 미리보기까지 보여준다.

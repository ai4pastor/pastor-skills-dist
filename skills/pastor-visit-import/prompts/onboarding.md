# 온보딩 — 처음 한 번, 세 가지만

목표: 볼트 위치와 폴더 둘(심방 노트·성도 노트)을 정해 `visit_env.py --save` 로 저장한다. 한 번에 한 질문만 한다.

## 1. Obsidian 볼트 폴더가 어디인가요?

`visit_env.py` 출력의 `vault_hint` (다른 pastor 스킬이 기억한 볼트)가 있으면 "이 볼트가 맞나요?" 로 먼저 제안한다.
없으면 흔한 위치를 함께 보여 드린다 — 맥: `~/Documents`, iCloud 옵시디언 폴더, `~/OneDrive`, `~/Google Drive` /
윈도우: `C:/Users/이름/Documents`, `C:/Users/이름/OneDrive`, `C:/Users/이름/Google Drive`. `.obsidian` 폴더가 있는 곳이 볼트다. 목사님 파일은 읽기만 한다.

## 2. 심방 노트가 들어 있는 폴더는 어디인가요?

모르시거나 여러 곳이면 폴더 없이 진단을 돌려 후보를 보여 드린다:

```bash
python3 scripts/audit_visits.py --vault "<볼트>" --table
```

`후보 폴더:` 에 심방일지가 많은 폴더부터 나온다. 여러 폴더면 `--folder` 를 여러 번 쓰되, **플러그인 설정에는 폴더 하나만**
들어가므로 "앞으로 심방일지를 모아 둘 폴더" 를 하나 정해 주시도록 여쭌다(기존 노트는 옮기지 않는다 — 설정 폴더 밖의 일지는
플러그인 대시보드에 안 보일 뿐이다).

## 3. 성도(교인) 노트 폴더는 어디인가요?

없으면 "없음" 으로 받고, Step 5 에서 `--create-missing` 으로 만들 폴더 이름을 여쭌다(예: `성도`). 성도 노트 폴더 안에
심방일지 폴더를 두어도 된다(플러그인 기본 구조: `성도/` 와 `성도/심방일지/`).

## 저장

```bash
python3 scripts/visit_env.py --save "vault=<볼트>" "member_folder=<성도 폴더>" "visit_folder=<심방 폴더>"
```

폴더는 **볼트 기준 상대 경로**로 저장한다(플러그인 설정값과 같은 형식). 윈도우 경로는 슬래시(`/`)로.

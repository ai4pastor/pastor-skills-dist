# pastor-sermon-import 설치 안내

설교 파일을 Obsidian vault에 자동 정리해 주는 Claude Code 스킬입니다.
설치와 사용 모두 목사님의 파일을 지우거나 고치지 않습니다.
실제로 노트를 만들기 전에는 항상 미리보기를 먼저 보여주고 승인을 받습니다.

## 설치 (명령 두 줄)

Claude Code를 열고 그대로 입력해 주세요.

```text
/plugin marketplace add ai4pastor/pastor-skills-dist
```

```text
/plugin install pastor-skills@ai4pastor
```

설치가 끝나면 `/`를 입력했을 때 목록에 `pastor-skills:pastor-sermon-import`가 보입니다.

> **예전에 zip으로 설치하셨던 분**
> `~/.claude/skills/pastor-sermon-import/` 폴더를 지워 주세요. 그대로 두면 같은 스킬이 두 개로 보입니다.
> 설정 파일(`~/.pastor-sermon-import/config.json`)은 **지우지 마세요** — 그대로 계속 쓰입니다.

## 읽을 수 있는 파일 형식

| 형식 | 준비물 |
|---|---|
| `.txt` · `.md` | 없음 |
| `.hwpx` (한글 표준 문서) | 없음 |
| `.docx` (워드) | pandoc 또는 python-docx — **스킬이 설치해 드립니다** |
| `.pdf` | pdftotext 또는 pypdf — **스킬이 설치해 드립니다** |
| `.hwp` (한글) | pyhwp — **스킬이 설치해 드립니다** |

필요한 도구가 없으면 스킬이 먼저 여쭤보고, 승인하시면 **스킬 전용 폴더에만** 설치합니다
(`~/.pastor-sermon-import/tools/pylibs`). 시스템 파이썬은 건드리지 않고 관리자 권한도
필요하지 않습니다. 설치가 어려우면 한글·워드에서 `.txt`(또는 `.hwpx`)로 저장하시면
추가 도구 없이 읽습니다. 스캔한 PDF(글자가 아니라 사진인 PDF)는 읽지 못합니다.

**구글 드라이브·원드라이브에 있는 설교**도 폴더만 알려 주시면 됩니다. 단
① 파일이 컴퓨터에 내려와 있어야 하고(클라우드에만 있으면 0바이트로 보입니다),
② 구글 문서(`.gdoc`)는 링크 한 줄이라 드라이브에서 `.docx`로 내려받아야 합니다.

## 준비물

1. **Claude Code**
2. **Python 3** (대부분의 환경에 이미 있습니다)

## 사용 (4단계)

1. **처음 한 번 — 설정**: `/pastor-sermon-setup`
   설교 원고 위치(구글 드라이브 등 볼트 밖도 됩니다), 설교 구분(대예배·수요·새벽 …),
   저장 폴더, 분류 방식을 하나씩 물어봅니다.
   분류(WORD)는 세 가지 중에 고르실 수 있습니다 — 목사님이 이미 쓰는 분류 노트를
   읽어 오기(템플릿·900번대 폴더에서 찾아 드립니다) / 강의 표준 프리셋 / 분류 없이 쓰기.
2. **미리보기**: `/pastor-sermon-import {설교 파일 또는 폴더 경로}`
   어떤 노트가 만들어질지 목록을 먼저 보여줍니다. **이 단계에서는 아무것도 생기지 않습니다.**
3. **실제 반영**: 미리보기를 확인하고 승인하시면 그때 노트가 만들어집니다.
4. **검증**: 만든 뒤 링크와 분류가 올바른지 자동으로 검사해 보고합니다.

## 업데이트

```text
/plugin marketplace update ai4pastor
```

```text
/plugin update pastor-skills@ai4pastor
```

설정 파일은 스킬 폴더 밖에 있으므로 업데이트해도 그대로 유지됩니다.

## 안심하셔도 되는 것

- 원본 설교 파일은 절대 수정·이동·삭제되지 않습니다.
- 이미 있는 노트는 덮어쓰지 않습니다. 같은 이름이 있으면 멈추고 물어봅니다.
- 승인하기 전에는 vault에 아무 파일도 생기지 않습니다.
- 도중에 실패해도 원본은 그대로입니다. 파일 하나가 실패해도 나머지는 계속 처리됩니다.

## Windows에서 확인할 것

- **폴더 경로**: `C:\Users\이름\...` 처럼 역슬래시(`\`)를 쓰는데, 설정에 넣을 때는
  `C:/Users/이름/...` 처럼 슬래시(`/`)로 바꿔 주시면 가장 안전합니다.
- **`python3`가 없다고 나올 때**: `py -3`으로 바꿔 실행해 달라고 Claude에게 말씀하시면 됩니다.
  (Microsoft Store 안내창이 열리면 그 창을 닫고 이렇게 알려 주세요.)

## 자주 묻는 질문

**Q. `.docx`·`.hwp`·`.pdf` 파일이 실패 목록에 나옵니다.**
A. 변환 도구가 없어서입니다. "설교 파일 읽는 도구 설치해줘" 라고 하시면 스킬 전용 폴더에
   설치합니다. 그래도 안 되면 한글·워드에서 `.txt`(또는 `.hwpx`)로 저장해 쓰셔도 됩니다.

**Q. 성경구절 링크가 옵시디언에서 빨갛게(끊긴 링크로) 보입니다.**
A. 성경구절 노트가 아직 없는 구절입니다. 링크 형식은 `[[요3_16]]` 표준을 따르므로,
   성경구절 노트가 만들어지면 자동으로 연결됩니다. 설정에서 성경구절 폴더를 알려 주시면
   검증 단계에서 몇 개가 빨간 링크인지 함께 알려 드립니다.

**Q. 같은 제목의 설교 조각이 이미 있으면 어떻게 되나요?**
A. 기본값은 **건너뛰기**입니다. 기존 조각은 손대지 않고, 새 설교 노트의 링크만 그 조각으로
   연결합니다. 설정에서 **병합**을 고르시면 기존 조각 끝에 새 글머리만 추가되고
   분류·날짜(frontmatter)는 그대로 유지됩니다. 중복된 글머리는 추가되지 않습니다.

**Q. 설정을 바꾸고 싶습니다.**
A. `/pastor-sermon-setup`을 다시 실행하시면 됩니다.
   설정 파일 위치는 Claude에게 "설정 파일 경로 알려줘"라고 하시면 알려 드립니다.

**Q. 플러그인 설치가 안 됩니다.**
A. 회사·학교 네트워크에서 GitHub이 막혀 있으면 실패할 수 있습니다. 그때는 받으신 zip 파일의
   압축을 풀어 `pastor-sermon-import` 폴더를 `~/.claude/skills/` 아래에 넣어 주세요.
   폴더 안에 `SKILL.md`가 바로 보이면 올바르게 설치된 것입니다.

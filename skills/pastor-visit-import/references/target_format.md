# 플러그인이 읽는 형식 (정본 — a4p-pastoral-visit `src/constants.ts` 와 같다)

## 심방일지

- 프론트매터 `type: 심방일지` 가 있어야 일지로 인식한다. 성도와의 연결은 **`성도: "[[이름]]"`** 하나뿐이다(본문 링크는 장식).
- `날짜: YYYY-MM-DD` — 플러그인의 '반영'은 이 형식이 아니면 거부한다. `심방유형` 은 기본 `정기심방`·`특별심방`·`위로심방`(설정에서 추가 가능).
- `반영: true` — 성도 노트에 반영됐다는 표시. 없으면 대시보드 "미반영 일지" 카드에 뜬다.
- 본문 H2 7개(이모지 포함이 표준. 이모지 없이 `## 대화내용` 도 인식하지만 **H2 만**, `###` 은 인식하지 않는다):

```markdown
## 📋 기본정보
## 📍 심방정보
## 📝 대화내용
- **주요 대화 주제:**
  - **주제 라벨:** 내용          ← 성도 노트 요약줄은 이 볼드 라벨 상위 2개로 만든다
## 🙏 기도제목
- **본인 기도제목:**
  - 기도 하나                     ← 일반 불릿. 끝에 `✅ 2026-04-12` 를 붙이면 "응답됨"
## ⛪ 교회 관련
## 🔍 관찰 및 평가
## 💡 후속조치
- [ ] 할 일                       ← 체크박스가 대시보드 후속조치 카드에 모인다
```

- 파일명 규칙 `{YYMMDD}_심방일지_{이름}.md` 는 플러그인이 **새 일지를 만들 때** 쓰는 규칙이다. 기존 노트는 다른 이름이어도 인식된다.

## 성도 노트

- 프론트매터 `type: 교인노트`. 이름은 **파일명**이다(`이름` 키는 Bases 용). 대시보드가 쓰는 키: `생년월일`(생일 카드), `등록일`(새등록 카드),
  `심방상태`(필요/완료/불필요), `가족관계`(`"[[이름]] (배우자)"`), `구역`·`직분`·`연락처`.
- 플러그인이 관리하는 두 섹션(없으면 첫 반영 때 문서 끝에 만든다):

```markdown
## 📝 심방 기록

- [[260308_심방일지_홍길동]] — 정기심방 (2026-03-08), 주제1, 주제2

## 📌 중요 심방 내용 (임베드)

### 2026-03-08 정기심방
![[260308_심방일지_홍길동#📝 대화내용]]
![[260308_심방일지_홍길동#🙏 기도제목]]
![[260308_심방일지_홍길동#💡 후속조치]]
```

임베드 앵커(`#📝 대화내용`)는 **일지의 실제 헤딩 텍스트**다. 일지 헤딩이 `## 대화내용`(이모지 없음)이면 앵커도 `#대화내용` 으로 쓴다
— 이 스킬의 `backfill_members.py` 가 그렇게 맞춘다.

## 이 스킬이 하는 변환 (요약)

| 원래 | 변환 후 | 분류 |
|---|---|---|
| `### 대화내용` (예전 템플릿의 `## 심방내용` 아래) | `## 📝 대화내용` (`## 심방내용` 은 그대로) | 교정 |
| `## 기도 제목`, `## 기도`, `## 중보기도` | `## 🙏 기도제목` | 교정 |
| `## 후속조치`, `## 할 일`, `## TODO` | `## 💡 후속조치` | 교정 |
| 프론트매터 `date: 2026-06-15` 만 있음 | `날짜: 2026-06-15` 추가 (`date:` 유지) | 추가 |
| `type` 없음 | `type: 심방일지` 추가 | 추가 |
| 체크된 `- [x] 정기심방` | `심방유형: 정기심방` 추가 | 추가 |
| 자유형 "기도: …" 줄 | `## 🙏 기도제목` 아래로 이동 (원문 그대로) | 이동 |
| `type: note` 등 다른 값 | 손대지 않음 | 보류 |

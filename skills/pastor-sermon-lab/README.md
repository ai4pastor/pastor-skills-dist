# pastor-sermon-lab

설교 준비를 돕는 배포형 Claude Code 스킬입니다. **설정 과정이 없습니다** —
설치 후 바로 요청하면 문서를 만들어 보여주고, 어느 폴더에 넣을지 여쭤본 뒤
Obsidian vault에 저장합니다.

## 3개 모드

| 모드 | 하는 일 | 결과물 |
|---|---|---|
| 연구 | 본문·주제의 원어·배경·역사·신학 연구자료 생성. 핵심 사실은 웹 교차검증 후 신뢰 등급(✅🟡⚠️❓🚫) 표기 | 연구노트 |
| 진단 | 설교 초안을 회중의 귀로 듣고 고정 6차원 루브릭으로 진단. 같은 폴더의 지난 진단노트와 비교해 반복 약점을 짚음 | 진단노트 |
| 보강 | 완성된 설교에 추가 자료·다른 관점·놓친 배경 제안 (설교문은 고치지 않음) | 보강노트 |

## 다른 스킬과 다른 점

- **설정 없음** — vault 위치는 첫 저장 때 한 번 물어보고 기억합니다. 이후엔
  "어느 폴더에 넣을까요?"만 묻습니다 (지난번 폴더를 기본값으로 제안).
- **등급이 선언이 아니라 증거에서 나옵니다** — ✅확인됨은 독립 출처 2개(기관 도메인 포함)의
  URL 증거 없이는 스크립트가 통과시키지 않습니다 (`verify_claims.py`).
- **진단이 쌓입니다** — 진단노트 frontmatter에 6차원 점수가 기록되어, 다음 진단 때
  지난 노트들을 읽고 "지난번에도 적용이 약점이었습니다"를 짚어줍니다.

## 구성

- `SKILL.md` — 스킬 본문 (모드 라우팅 + 저장 흐름)
- `INSTALL.md` — 수강생용 설치 안내
- `prompts/` — 모드별 규칙·웹검증 프로토콜·셀프체크 (해당 모드에서만 로드)
- `references/` — 등급 규칙·연구노트 개요·진단 루브릭
- `data/` — 성경 장 수·금지 표현·기관 도메인 목록
- `scripts/` — 결정론 처리 (게이트·노트 생성·검증·vault 기억)

## 설계 원칙

- 원본 파일 보존, 기존 노트 덮어쓰기 금지, 미리보기 + 폴더 확인 후 저장
- 내용은 Claude(LLM)가, 등급 검증·파일 생성·집계는 스크립트가 결정론적으로
- 설교문·개인 정보는 웹 검색 질의에 넣지 않음
- 스킬이 기억하는 것은 vault 경로·최근 폴더·회중 한 줄뿐 (`~/.pastor-sermon-lab/memory.json`)

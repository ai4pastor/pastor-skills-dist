# 자유형 심방 노트 매핑 — LLM 계획(llm_plan.json) 작성 규칙

`plan_visits.py` 의 `needs_llm` 에 오른 노트만 대상이다. 노트를 읽고 **줄 번호 기반 JSON** 을 쓴다.
문장을 다시 쓰거나 요약하거나 새 문장을 만들지 않는다. 옮길 줄의 **원문 첫 줄**을 `first_text` 에 그대로 적는다
(스크립트가 대조해 다르면 그 항목을 버린다). 줄 번호는 0부터, 파일 전체 기준(프론트매터 포함)이다.

## 출력 (파일: `<work>/llm_plan.json`)

```json
{
  "notes": [
    {
      "path": "심방/2026-05-10 김철수 심방 메모.md",
      "sha1": "<audit.json 의 sha1 그대로>",
      "member_name": "김철수",
      "frontmatter_add": { "날짜": "2026-05-10", "심방유형": "특별심방" },
      "new_sections": ["## 📝 대화내용", "## 🙏 기도제목", "## 💡 후속조치"],
      "heading_fixes": [ { "line": 7, "from": "## 기도 부탁", "to": "## 🙏 기도제목" } ],
      "moves": [
        { "lines": [5, 6], "first_text": "기도: 면접 결과에 흔들리지 않는 믿음", "to": "## 🙏 기도제목" },
        { "lines": [7, 8], "first_text": "- 청년부 담당 전도사에게 연결하기", "to": "## 💡 후속조치" }
      ]
    }
  ]
}
```

## 규칙

- `to` 는 플러그인 7개 헤딩 중 하나만: `## 📋 기본정보` `## 📍 심방정보` `## 📝 대화내용` `## 🙏 기도제목` `## ⛪ 교회 관련` `## 🔍 관찰 및 평가` `## 💡 후속조치`.
- **기도제목 신호**: "기도", "중보", "위해", "~하도록", "~되길" 로 끝나는 줄·불릿. **후속조치 신호**: 체크박스, "~하기", "연락", "전달", "확인", "연결", "다음 주".
  **대화내용**: 그 밖의 서술. 확신이 없으면 옮기지 말고 그대로 둔다(대화내용 섹션에 남는다).
- `moves` 의 범위는 연속된 줄만, 서로 겹치지 않게. 헤딩 줄은 옮기지 않는다(헤딩은 `heading_fixes` 로).
- 본문이 헤딩 없이 시작하면 `new_sections` 에 세 앵커 섹션을 넣고, 서술 줄은 옮기지 않아도 된다 —
  스크립트가 섹션을 **문서 끝**에 만들고, 옮기지 않은 줄은 제자리에 남는다. 플러그인은 `## 📝 대화내용` 아래 내용으로 요약을 만들므로,
  핵심 서술 몇 줄(첫 문단)을 `## 📝 대화내용` 으로 옮기는 편이 좋다.
- `frontmatter_add` 에는 노트에서 **읽어 낸** 값만(제목·본문의 날짜, 체크된 유형). 없으면 키를 넣지 않는다. 심방유형은 정기심방·특별심방·위로심방 중 하나가 자연스러울 때만.
- `member_name` 은 노트에 적힌 이름에서 호칭(집사님·권사님·성도 등)을 뗀 것. 성도 폴더에 같은 이름이 없으면 스크립트가 "새로 만듦" 후보로 다룬다.
- 노트에 여러 사람·여러 날짜의 심방이 섞여 있으면 계획을 쓰지 말고 `hold` 로 보고한다: `{"path": "...", "hold": "여러 날짜가 섞여 있음 — 사람이 나눠야 함"}`.

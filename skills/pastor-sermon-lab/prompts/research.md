# 연구 모드 — 본문·주제 연구노트 생성 규칙 (v3)

목사님이 준 성경 본문 또는 주제로 설교 준비용 연구노트 1개를 만든다.
섹션 구성·개수(quota)·분량은 `references/research_outline.md`,
각 섹션의 작성 방법론은 `references/method_guide.md`,
등급 규칙은 `references/grade_rules.md`, 웹 검증 절차는 `prompts/verify_facts.md`를 따른다.

## 절차

1. **범위·분량 확인**: 본문(장절)인지 주제인지 판별한다. 본문이 여러 장에 걸치면 목사님께
   범위를 확인한다. 분량 단계는 기본 **표준** — 목사님이 "간단히"면 간단, "자세히/깊이"면
   상세 (별도 질문은 하지 않는다).
2. **관찰 먼저**: outline 섹션 1·2·4·6(관찰 구역)을 본문만으로 초안한다. 이 단계에서는
   웹 검색을 하지 않는다.
3. **주장 원장 작성**: 노트에 들어갈 외부 사실 주장을 `~/.pastor-sermon-lab/work/claims.json`에
   정리한다 (스키마는 `scripts/verify_claims.py` 문서화 참조). 각 주장에 유형(T1~T5/기타),
   load_bearing 여부, 잠정 등급, source를 기록한다.
4. **웹 교차검증**: `verify_facts.md`의 프로토콜대로 검증하고 evidence를 원장에 기록한다.
5. **게이트**: `python3 scripts/verify_claims.py ~/.pastor-sermon-lab/work/claims.json` 통과까지 등급을 수정한다.
6. **본문 작성**: 아래 result JSON을 `~/.pastor-sermon-lab/work/research.json`에 저장한다.
7. 이후 SKILL.md 흐름 Step 3~6을 따른다 (미리보기 → 폴더 확인 → 저장 → 검증).

## result JSON 스키마

```json
{
  "title": "노트 제목 (명제형, 30자 이내)",
  "topic": "파일명에 들어갈 짧은 주제어",
  "date": "YYYY-MM-DD (오늘)",
  "main_passage": "요 1:1-18",
  "verification_status": "웹검증 완료 | 오프라인",
  "search_count": 0,
  "tags": ["한단어태그"],
  "body": "## 섹션...\n(마크다운 본문)"
}
```

## body 작성 규칙

- 섹션 순서·quota·negative report 대상은 `research_outline.md`를 따른다 (수치를 임의로
  바꾸지 않는다).
- **관찰 3원칙** — `(관찰)` 섹션에서는:
  1. 성경 본문에서 직접 확인 가능한 서술만 쓴다 (본문 내용 서술은 등급 비대상 규정 근거).
  2. 연대·세기·통계·학자 실명·외부 문헌은 금지 — 그런 내용은 등급을 붙여 "역사·문화 배경"
     등 사실 섹션에 쓴다. 게이트(verify_note.py)가 위반을 차단한다.
  3. 따옴표는 직선(`"` `'`)만 — 곡선 따옴표는 사실 신호로 간주되어 차단된다.
- 무표기 섹션의 모든 사실 주장 문장 끝에 등급 이모지 1개. 해석 섹션은 제목에 `(해석)`.
- 원어는 원문 + 영어 음역 + 한글 발음 3중 병기: `로고스(λόγος, logos, 로고스)`.
- 성경구절은 자연스럽게 본문에 표기만 한다 (`요 3:16`) — wikilink는 스크립트가 만든다.
  평행 본문 섹션은 반드시 절 번호까지 (`창 5:24`, 장만 쓰면 링크가 안 걸린다).
- `## 검증 요약` 섹션은 쓰지 않는다 — `build_note.py`가 실측값으로 생성한다.
- 🚫 판정 항목은 본문에 사실로 쓰지 말고 `## 주의 — 사용하지 마십시오` 박스에만 기록한다.
- 방법론 학자명(가이드 출처)은 노트 본문에 쓰지 않는다.
- 내용은 본문 연구 자료다. 완성된 설교문을 쓰지 않는다 — 설교는 목사님의 몫이다.

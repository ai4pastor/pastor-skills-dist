# Onboarding Prompt (basic)

목표: 폴더 위치 몇 개만 받아 설정을 완성한다. **질문은 5개다.**

## 진행 원칙

- 한 번에 한 질문만 한다.
- **빈칸을 타이핑하게 두지 않는다.** 볼트를 먼저 읽고 후보를 번호로 제시한다.
- 목사님이 "잘 모르겠다"고 하면 가장 그럴듯한 후보를 권하고 이유를 한 줄로 말한다.
- 파일명 규칙·저장 형식·검증 규칙은 **묻지 않는다.** 추론하고 확인만 받는다.
- 설정 파일을 쓰기 전 미리보기를 보여주고 승인을 받는다.

## 질문 1. 옵시디언 볼트가 어디에 있나요?

폴더 경로를 알려 주세요. (옵시디언에서 볼트 이름을 오른쪽 클릭 →
"Reveal in Finder" 로 확인하실 수 있습니다.)

받으면 바로 실행한다:

```bash
python3 scripts/suggest_folders.py "{볼트 경로}"
```

폴더를 못 찾으면 경로를 다시 여쭤본다. 이 출력이 질문 2~4의 선택지가 된다.

## 질문 2. 설교 원고 파일이 어디에 있나요?

`.docx` / `.md` / `.txt` 설교 파일이 든 폴더입니다.
**볼트 밖이어도 됩니다** — 원본은 건드리지 않고 읽기만 합니다.

받으면 바로 실행한다:

```bash
python3 scripts/guess_naming.py "{설교 폴더}"
```

그리고 결과를 이렇게 보여주고 **확인만** 받는다:

```text
설교 파일 {files_scanned}개를 살펴봤습니다.

  {samples 를 표로: 파일명 → 날짜 / 대상 / 제목}

{explain}

이렇게 읽으면 될까요?
```

- 틀린 것이 있으면 그 항목만 고친다.
- 맞으면 `suggested` 값을 그대로 config에 넣는다.
- `date_ratio`가 0.5 미만이면 "날짜가 없는 파일이 많습니다 — 노트 이름에서 날짜를
  빼고 제목만 쓸까요?"를 함께 여쭤본다.

## 질문 3. 정리된 설교 노트를 볼트 어느 폴더에 넣을까요?

`suggest_folders.py` 의 `sermon_folders` 후보를 번호로 제시한다.

`sermon_folders` 의 각 항목을 `path` (노트 `notes` 개) 형태로, 점수 높은 순으로 번호를 붙인다.

```text
볼트에서 설교 관련 폴더를 찾았습니다.

  1) {후보 1 path}        (노트 {notes}개)
  2) {후보 2 path}        (노트 {notes}개)
  3) {후보 3 path}        (노트 {notes}개)
  4) 직접 입력하겠습니다
  5) 새 폴더를 만들어 주세요 (이름을 알려 주세요)

어디에 넣을까요?
```

노트 수가 가장 많은 후보를 먼저 권하고 이유를 한 줄로 말한다.
후보가 없으면 새로 만들 이름을 여쭤보고 기본값 `설교`를 권한다.

## 질문 4. 설교 조각(작은 메모)은 어느 폴더에 넣을까요?

`fragment_folders` 후보를 같은 방식으로 제시한다. 후보가 없으면 `설교조각`을 권하되,
질문 3에서 고른 설교 폴더가 번호 체계(`숫자. 이름`)를 쓰고 있으면 그 체계에 맞춘
이름을 함께 제안한다.

조각이 무엇인지 한 줄로 설명한다:

```text
설교 한 편을 논지·해석·예화·적용 단위로 나눈 작은 메모입니다.
나중에 다른 설교를 준비하실 때 이 조각들이 검색·재사용됩니다.
```

## 질문 5. 분류(WORD)를 쓰시나요?

`suggest_folders.py` 의 `word_notes` 에 후보가 있으면 **그것부터 제시한다**:

`word_notes` 의 `path` 와 `matched_axes` 를 그대로 보여준다.

```text
분류를 정리해 두신 노트를 찾았습니다.

  1) {word_notes[0].path}
     ({matched_axes 를 "World N개 · Outcome N개 · Route N개 · Doctrine N개" 로})
  2) 강의 표준 분류표를 쓰겠습니다
  3) 분류는 쓰지 않겠습니다

어느 것으로 할까요?
```

- **1번**: `python3 scripts/parse_word_source.py "{경로}"` 로 읽고, 인식한 개수를
  보여주고 확인받는다. 못 읽은 축이 있으면 `--explain` 으로 찾는 모양을 안내한다.
  **그 노트는 수정하지 않는다.**
- **2번**: `data/word_preset.a4p.json` 을 읽어 허용 목록에 넣는다.
- **3번**: `use_word: false`. 조각 분해와 성경구절 링크는 그대로 동작한다.

1번·2번이면 아래를 **함께 켜고 따로 묻지 않는다**:

```json
"use_word": true,
"route_scalar": true,
"single_world": true,
"wrap_values_in_wikilink": true,
"fragment_world": "{조각용 World 값}"
```

`fragment_world` 는 프리셋의 `axes.world.fragment_recommended`, 또는 목사님 분류
목록에서 조각·영감 성격의 값을 찾아 제안한다. 못 찾으면 설교 World 값 중
하나를 쓸지 여쭤보거나 비워 둔다.

설교에 붙일 World 값은 질문 3에서 고른 폴더와 짝이 되는 것을 **제안**한다
(예: `310. 청소년부` → `📩 201 청소년부 설교`). 확인만 받는다.

## 마지막 출력

```text
이렇게 설정하겠습니다.

  볼트          {vault}
  설교 원고      {input}
  설교 노트      {main_folder}
  설교 조각      {fragment_folder}
  분류          {프리셋 / 목사님 노트 / 사용 안 함}
  노트 이름      {main_note_pattern}  (예: 260111_청_사도신경_롬4_17.md)
  성경구절 링크   [[요3_16]]
  같은 이름 노트  멈추고 물어봅니다

저장할까요? 저장하려면 "OK 저장"이라고 답해 주세요.
```

# pastor-visit-import 설치·사용 안내

지금까지 적어 오신 심방 노트를 **지우거나 다시 쓰지 않고** 심방 관리 플러그인(a4p-pastoral-visit)이 읽을 수 있게
다듬어 주는 Claude Code 스킬입니다. 노트를 고치기 전에는 항상 바뀔 내용을 먼저 보여 드리고 승인을 받습니다.

## 준비 두 가지

1. **플러그인** — Obsidian 커뮤니티 플러그인 BRAT 를 설치한 뒤 `Add a beta plugin` 에 `ai4pastor/a4p-pastoral-visit` 를 넣고 켭니다.
   (자세한 순서는 스킬 안의 `references/plugin_setup.md`. Claude 에게 "심방 플러그인 설치 순서 알려줘" 라고 하셔도 됩니다.)
2. **스킬** — `pastor-skills` 플러그인을 설치하셨다면 업데이트만 하시면 됩니다.

```text
/plugin marketplace update ai4pastor
```

```text
/plugin update pastor-skills@ai4pastor
```

처음이시면:

```text
/plugin marketplace add ai4pastor/pastor-skills-dist
```

```text
/plugin install pastor-skills@ai4pastor
```

## 쓰는 법 (한 문장이면 됩니다)

Claude Code 를 열고 이렇게 말씀하세요.

```text
심방 노트 플러그인 형식으로 바꿔줘
```

그다음은 Claude 가 순서대로 여쭙고 진행합니다.

1. 볼트 위치, 심방 노트 폴더, 성도 노트 폴더 (처음 한 번)
2. **진단** — 어떤 노트가 심방 기록인지, 어떤 모양인지 표로 보여 드립니다. 읽기만 합니다.
3. **미리보기** — 노트마다 무엇이 더해지고(프론트매터·빈 섹션) 어떤 헤딩 이름이 바뀌는지 diff 로 보여 드립니다.
4. **승인 후 적용** — 승인하신 것만 바꿉니다. 바꾸기 전 원본은 설정 폴더(볼트 밖)에 백업됩니다.
5. **성도 노트 연결** — 심방일지마다 성도 노트에 기록 한 줄과 임베드를 붙입니다. 성도 노트가 없는 분은 여쭤본 뒤 최소 노트를 만듭니다.
6. **검증 + 설정값** — 마지막에 플러그인 설정에 넣을 폴더 두 개를 그대로 알려 드립니다. 넣고 [검증] 을 누르시면 대시보드가 살아납니다.

## 안심하셔도 되는 것

- 노트를 지우거나 이름을 바꾸지 않습니다. 문장을 고치지도 않습니다.
- 바뀌는 것은 ① 헤딩 이름(예: `### 대화내용` → `## 📝 대화내용`) ② 프론트매터에 없던 키 추가(`type`·`성도`·`날짜`) ③ 줄을 알맞은 헤딩 아래로 옮기기(원문 그대로) 뿐입니다.
- 어떤 줄이라도 사라지면 스크립트가 그 노트를 멈추고 알립니다.
- 되돌리고 싶으시면 "방금 바꾼 거 되돌려줘" 라고 하시면 백업으로 복원합니다.

## 자주 묻는 질문

**Q. 예전 강의 때 받은 심방 템플릿(`## 심방내용` 아래 `### 대화내용`)으로 써 왔습니다.**
A. 가장 흔한 경우입니다. `### 대화내용` 같은 소제목을 플러그인이 읽는 `## 📝 대화내용` 으로 올려 주고, `## 심방내용`·`## 전달사항`·`## 메모` 같은 나머지 제목은 그대로 둡니다.

**Q. 헤딩 이름을 제 식대로 써 왔습니다 (예: "나눈 말씀").**
A. 설정 폴더의 `visit_rules.md` 에 `- 대화내용: 나눈 말씀` 처럼 적어 두시면 다음부터 자동으로 알아봅니다. Claude 에게 "내 헤딩 이름 규칙에 추가해줘" 라고 하셔도 됩니다.

**Q. 자유롭게 적은 메모도 됩니까?**
A. 됩니다. 그런 노트는 Claude 가 읽고 "이 줄은 기도제목, 이 줄은 후속조치" 로 **줄 단위 계획**만 세우고, 실제 이동은 스크립트가 원문 그대로 합니다. 문장을 바꾸거나 요약해 넣지 않습니다.

**Q. 성도 노트가 아예 없습니다.**
A. 심방일지의 성도 이름으로 최소 성도 노트(이름·심방상태)를 만들어 드릴지 여쭙니다. 승인하시면 만들고, 나머지 정보(생년월일·연락처 등)는 플러그인의 등록 모달이나 직접 입력으로 채우시면 됩니다.

**Q. 파일명도 `260615_심방일지_홍길동` 으로 바꿔 줍니까?**
A. 이번 판에서는 바꾸지 않습니다. 플러그인은 파일명이 아니라 프론트매터로 노트를 찾으므로 기존 이름 그대로 동작합니다. 새로 만드는 일지는 플러그인이 그 규칙으로 만듭니다.

## Windows에서

- 폴더 경로는 `C:/Users/이름/...` 처럼 슬래시로 적어 주시면 안전합니다.
- `python3` 가 없다고 나오면 `py -3` 으로 바꿔 실행해 달라고 Claude 에게 말씀하시면 됩니다.

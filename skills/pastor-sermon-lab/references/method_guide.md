# 연구 방법론 가이드 — 대가들의 기법 (정의는 이 문서에만)

각 섹션을 *어떻게* 만드는지의 단일 권위. 무엇을 몇 개 넣는지는 `research_outline.md`.
여기 나오는 학자명은 방법의 출처 표시일 뿐이다 — **노트 본문에는 방법론 학자명을 쓰지 않는다**
(관찰 섹션 금지 규칙과 별개로, 노트는 본문 연구 자료지 방법론 소개가 아니다).

## 1. 관찰 단계

### 본문 경계 확정 3질문 (Fee)

① 이 단락은 어디서 시작해 어디서 끝나는 사고 단위인가? ② 앞뒤 단락과 어떤 논리로
이어지는가? ③ 목사님이 준 범위가 사고 단위를 자르면 — 경계 조정을 제안한다 (자르지 않고 질문).

### 장르 분기표 (Osborne) — 개관에서 판정하고, 이후 전 섹션의 관찰 방식이 따라간다

| 장르 | 관찰 포인트 |
|---|---|
| 서신/논증 | 논증 흐름 속 위치, 접속사(그러므로·왜냐하면), 명령법과 직설법의 관계 |
| 내러티브 | 장면 구분, 등장인물의 시선·행동, 화자의 평가(직접 말하는 드문 순간), 플롯 긴장 |
| 시/시편 | 평행법 4종(동의·반의·종합·계단) 점검, 이미지의 감각, 화자의 감정 곡선 |
| 지혜 | 격언의 일반 원리성(약속이 아님), 대조 구조, 관찰-교훈 패턴 |
| 예언 | 심판/회복 신탁 구분, 1차 청중, 언약 배경(축복·저주 구조) |
| 묵시 | 상징은 본문·구약 인유에서 먼저 해석, 숫자·색·짐승의 관례적 용법 |
| 비유 | 중심 반전 1개 찾기(모든 세부에 의미 부여 금지), 청중이 놓인 자리 |
| 복음서 | 단락의 전후 배치 의도, 같은 사건의 타복음서 기록과 강조점 차이 |

### 간이 구조 디스플레이 (Kaiser 블록 다이어그램 축약형)

주절을 왼쪽 끝에, 수식·종속 요소를 그 아래 들여쓰기로 배열해 문단의 무게중심을 눈으로
보이게 한다. 성경 본문 어구만 사용하고 코드블록으로 감싼다. 예:

```
믿음은 ~이다 (1절, 주제 선언)
    바라는 것들의 실상
    보이지 않는 것들의 증거
        선진들이 이로써 증거를 얻음 (2절, 예화 목록 예고)
```

### 키아스무스·평행법 판정 규율

교차 대칭(A-B-B'-A')이 실제 어휘 반복으로 지지될 때만 인정한다. 없으면 "식별되지 않음"
1줄 + 실제 장치(반복어·수미상관·점층 등) 1줄. 억지 대칭 생성은 본문 곡해다.

## 2. 원어 단계 — Carson 3금지 (단어 연구 가드레일)

1. **어원 오류**: 어원·어근으로 의미를 단정하지 않는다 (예: 뒤나미스를 "다이너마이트 같은
   능력"으로 설명 — 후대 단어로 성경 단어를 풀이하는 시대착오이기도 하다).
2. **의미장 총합 전이**: 한 단어의 모든 용례 의미를 이 구절에 다 집어넣지 않는다.
   이 본문에서 저자가 쓴 의미 하나를 문맥으로 정한다.
3. **동의어 과잉 구분**: 문체 변화일 수 있는 유의어 교체(예: 두 "사랑" 동사)에 항상
   신학적 차이를 부여하지 않는다.

단어 의미는 어원이 아니라 **저자의 용법**으로 결정한다. 특정 사전·문법서를 명시 인용하면
T2 주장이 된다 — 원장 등록과 검증 없이는 서지명을 쓰지 않는다.

## 3. 배경 단계 — 전경(foreground) (Stuart)

배경(이 본문 이전·당시)만이 아니라 **전경** — 이 본문·사건이 이후 성경 역사와 계시 전개에
남긴 자취 — 를 1항목 이상 본다. 예: 에녹 기사가 후대 유대 문헌과 신약(유 1:14)에서 어떻게
회고되는가. 전경도 외부 사실이면 등급 대상이다.

## 4. 해석 단계

### 교리 추출 (Lloyd-Jones)

각 단락에서 "이 본문이 하나님·인간·구원에 관해 가르치는 것"을 명제로 뽑는다.
황금률은 정직 — **본문이 실제로 지지하지 않는 교리를 본문에 말하게 하지 않는다.**

### 3층 문맥 (Osborne)

추출한 주제를 ① 이 본문에서 → ② 이 책 전체에서 → ③ 정경 전체에서 각 1문장씩 자리매김한다.

### 주제-보어 분석 (Robinson)

① 주제: "이 본문은 **무엇에 대해** 말하는가?" (완전하고 한정적으로) ② 보어: "그것에 대해
**정확히 무엇을** 말하는가?" 둘을 합친 것이 주해적 아이디어 1문장(원청중 시점).
설교적 아이디어는 그것을 오늘 청중의 언어로 옮긴 것 — **후보 2~3개로 병기하고 확정하지
않는다** (본문은 한 문장으로 환원되지 않는다는 비판을 수용).

### saying/doing 2열 표 (Kuruvilla)

| 저자가 말하는 것 (내용) | 저자가 이 본문으로 하려는 일 (의도) |
같은 본문을 내용과 화행(설득·경고·위로·예배로 초대…)으로 나눠 적으면 착안점이 선명해진다.

## 5. 착안 단계

### 타락 상황 초점 FCF (Chapell)

3질문: ① 본문이 무엇을 말하는가 ② 원청중의 어떤 영적 문제를 다뤘는가 ③ 오늘 회중이
원청중과 공유하는 그 문제는 무엇인가. FCF는 본문 주해에서 나와야 하며(외부 주입 금지)
1문장으로. 반드시 **본문 속 하나님의 행동/은혜**와 짝지어 제시한다.

**Deadly Be 경고**: "~처럼 되라 / 착하게 살라 / 더 훈련하라"만 남는 착안점은 은혜 없는
도덕주의다. 명령이 있다면 그 명령을 가능케 하는 본문 속 은혜를 먼저 밝힌다.

### 그리스도께 가는 7길 (Greidanus)

① 구속사적 진행(이 본문의 하나님 행동이 그리스도에게서 절정에 이르는 흐름)
② 약속-성취 ③ 모형론(하나님이 세우신 제도·인물·사건의 예표) ④ 유비(이스라엘에게
하나님이셨던 것 = 교회에게 그리스도) ⑤ 종적 주제(본문 주제가 정경을 관통해 그리스도까지
발전) ⑥ 신약 인용(신약이 이 본문을 직접 인용·암시) ⑦ 대조(본문과 그리스도 사이의 차이가
복음을 드러냄). 전제: 본문을 원래 정황에서 먼저 이해한 뒤에 적용한다. 알레고리는 쓰지
않는다. **해당 없는 길은 "해당 없음"** — 7길 전부를 억지로 채우는 것이 실패다.

### 두 세계 다리 (Stott) + 회중의 마음 (Keller)

본문 세계의 상황과 오늘 세계의 대응 상황을 병렬표로 놓는다. 오늘 쪽에는 회중이 실제로
품을 질문·반론과, 본문 주제가 건드리는 우상 후보(권력·인정·안락·통제 4범주에서)를
2~3개 적는다. 회중 정보를 검색하거나 추측하지 않는다 — 일반적 인간 경험 수준까지만.

### 발전 방향 판정 (Robinson 3대 발전 질문)

이 본문의 설교는 ① 설명("이것이 무슨 뜻인가"가 관건) ② 증명("청중이 이것을 믿기
어려워한다") ③ 적용("뜻은 알지만 삶이 안 따라간다") 중 어디에 무게를 둘 본문인지
1줄로 판정하고 근거를 붙인다.

## 6. 기본 산출에서 제외하는 견해 (논쟁적 소수 견해)

- **선행 계시 제한 해석**(본문보다 시간적으로 앞선 계시만 해석에 동원): 무엇이 '선행'인지
  판단이 주관적이라는 비판이 커서 기본값으로 쓰지 않는다.
- **christiconic 해석**(모든 본문이 그리스도 형상의 한 단면): 억지 적용 위험이 지적되어
  기본값으로 쓰지 않는다. 그리스도 연결은 7길 점검표로만 한다.

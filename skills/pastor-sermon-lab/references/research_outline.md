# 연구노트 섹션 구성 (v3) — 개수·분량의 단일 권위

기본 구성은 본문 입력 기준. 주제 입력이면 "본문 개관 (관찰)" 대신 "주제 개관"과
"관련 본문"을 쓰고, 본문 의존 섹션(2·4·6)은 대표 본문 1개를 정해 적용한다.
방법론(각 항목을 *어떻게* 만드는지)은 `method_guide.md`에만 있다 — 여기서는 무엇을·몇 개.

## 구역 표기 (verify_note.py가 강제)

- `(관찰)` 섹션 = 성경 본문에서 직접 확인 가능한 서술 전용. 연대·통계·학자·외부 인용 금지.
- `(해석)` 섹션 = 신학적 해석·제안. 등급 없음.
- 무표기 섹션 = 외부 세계 사실. 사실 주장 문장마다 등급 이모지 필수.

## 분량 3단계

기본값은 **표준**. 목사님이 "간단히"라고 하면 간단, "자세히/깊이"라고 하면 상세.

| 필드 | 간단 (A4 1~2장) | 표준 (A4 3~5장) | 상세 (A4 6~8장) |
|---|---|---|---|
| 본문 구조 단락 | 표만 2~3 | 2~5 | 3~6 |
| 원어: 단어 / 구문 | 2 / 0~1 | 2~4 / 1~3 | 3~5 / 2~4 |
| 번역 비교 갈림점 | 1~2 | 2~4 | 3~6 |
| 배경 항목 (전경 포함) | 2~3 | 3~6 | 5~8 |
| 평행 본문 | 2~3 | 3~5 | 4~7 |
| 설교적 아이디어 후보 | 2 | 2~3 | 3 |
| 착안점 4축 | (a)(c)만 | 4축 전부 | 4축 + 각 축 심화 |

- 간단 단계에서는 섹션 2(단락 표만 남김)·7·8을 기본 생략한다.
- quota 미달 시 삭제하지 말고 미달 이유를 1줄로 남긴다 (예: "본문이 짧아 구문 쟁점 없음").

## 필수 섹션 (순서 고정)

1. `## 본문 개관 (관찰)` — 본문 경계 확정 근거(왜 여기서 시작·끝나는가), 앞뒤 문맥,
   장르 식별(method_guide의 8장르 분기표 적용, 어느 장르 규칙을 따랐는지 1줄 명시). 3~6문장.
2. `## 본문 구조 (관찰)` — ① 단락 분할 표(단위|절|역할), ② 간이 구조 디스플레이
   (주절 왼끝·수식어 들여쓰기, 반드시 코드블록으로 감쌈), ③ 수사적 흐름 2~3문장,
   ④ 키아스무스·평행법 판정 — **negative report 대상**: 없으면 "식별되지 않음" + 실제
   구조 장치 1줄. 억지 구조 생성 금지.
3. `## 원어 요점` — 핵심 단어(3중 병기: 원문+영어 음역+한글 발음), 의미 범위,
   본문에서의 쓰임 + 결정적 구문(시제·태·격·접속사). 품사 변화표·어형 전체 나열 금지.
   Carson 3금지(method_guide) 준수. 사전·문법서·학자 실명 인용은 T2/T4로 원장 등록 + 등급.
4. `## 번역 비교 (관찰)` — 개역개정·새번역·NIV·ESV 표(지점|각 역본|차이의 의미).
   따옴표는 직선(`"` `'`)만. 갈림이 학계 논쟁을 반영하면 "학계 논쟁" 섹션과 연결만 한다.
5. `## 역사·문화 배경` — 시대 상황·관습·지리 + 전경(이 본문이 이후 성경 역사·계시에
   남긴 자취) 1항목 이상. **사실 주장마다 등급 필수.**
6. `## 평행 본문 (관찰)` — 구약 연결 + 신약 유사 본문. 각 항목: `책 장:절` 표기(절 번호
   필수 — 장만 쓰면 wikilink가 안 걸림) + "왜 함께 봐야 하는가" 1줄. 본문 간 관계는
   성경 본문 관찰로만 서술한다.
7. `## 신학 주제 (해석)` — 본문이 가르치는 교리 1~3개 + 3층 문맥(본문→책 전체→정경 전체)
   각 1문장 이상. 교단 전통을 존중하되 단정하지 않는다.
8. `## 중심 명제 후보 (해석)` — ① 주제-보어 표(무엇에 대해|무엇을 말하는가),
   ② 주해적 아이디어 1문장(원청중 시점), ③ 설교적 아이디어 후보(청중 언어 — 확정하지
   않고 후보로 병기), ④ saying/doing 2열 표(저자가 말하는 것|이 본문으로 하려는 일).
9. `## 설교 착안점 (해석)` — 4축 순서 고정:
   - (a) **타락 상황 초점(FCF)**: 원청중과 오늘 회중이 공유하는 영적 문제 1문장 + 본문 속
     하나님의 행동/은혜 1문장.
   - (b) **그리스도께 가는 길**: 7길 표(길|해당|근거) — **negative report 대상**: 해당 없는
     길은 "해당 없음"으로 표기, 억지 연결 금지.
   - (c) **두 세계 다리**: 본문 세계↔오늘 세계 병렬표 + 회중이 품을 질문·반론·우상 2~3개.
   - (d) **발전 방향 판정**: 이 본문의 설교가 설명·증명·적용 중 어디에 무게를 둘지 1줄 + 근거.

## 조건부 섹션

- `## 본문비평 요점` — 주요 사본 차이가 있을 때만. **negative report 대상**: 상세 단계에서만
  "특기할 사본 차이 없음" 1줄 허용, 그 외 단계는 섹션 생략. "사본 차이의 절대다수는 교리에
  영향을 주지 않는다"는 목회적 안전 문장을 함께 쓴다.
- `## 학계 논쟁` — ⚠️ 등급 주장이 2개 이상일 때 양 진영을 표로 정리.
- `## 주의 — 사용하지 마십시오` — 🚫 판정 항목이 있을 때만 (위조 유물, 확인 실패 인용문 등).

## negative report 규칙 (3곳 한정)

부재를 명시하는 대상은 **키아스무스·평행법(섹션 2), 그리스도께 가는 7길(섹션 9b),
본문비평(조건부)** 3곳뿐이다. 다른 필드에서 "없음"을 나열하지 않는다.
부재 명시는 1~2줄로 짧게 — 왜 없다고 판단했는지가 정보다.

## 금지

- 완성된 설교문·설교 대지 작성 (착안점 제안까지가 한계).
- `## 검증 요약` 직접 작성 (스크립트 생성).
- 특정 주석서·설교자의 문장을 통째로 옮기기.
- 곡선 따옴표(" " ' ') — 전 섹션에서 직선 따옴표만 사용.
- (관찰) 섹션에 연대·세기·통계·학자 실명·외부 문헌 언급 — 게이트가 차단한다.

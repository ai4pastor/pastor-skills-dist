# pastor-sermon-basic 설치 안내

설교 파일을 Obsidian에 정리해 주는 Claude Code 스킬입니다.
**어디서 가져와, 어떻게 나눌지만 답하면 됩니다.** 나머지는 스킬이 컴퓨터와 볼트를
읽어 알아서 맞춥니다.

목사님의 파일을 지우거나 고치지 않습니다.
노트를 만들기 전에는 항상 미리보기를 보여주고 승인을 받습니다.

## 설치 (명령 두 줄)

Claude Code를 열고 그대로 입력해 주세요.

```text
/plugin marketplace add ai4pastor/pastor-skills-dist
```

```text
/plugin install pastor-skills@ai4pastor
```

## 쓰는 법

Claude Code에서 이렇게 말씀하시면 됩니다.

```text
설교 정리해줘
```

또는 설교가 있는 폴더를 알려 주셔도 됩니다.

```text
/pastor-sermon-basic ~/Documents/설교원고
```

### 처음 한 번 — 일곱 가지만 답하시면 됩니다

1. **옵시디언 볼트가 어디 있나요?** → 컴퓨터에서 찾아 후보를 보여드립니다
2. **설교 원고를 어디서 가져올까요?** → 구글 드라이브·원드라이브·iCloud·문서 폴더까지
   훑어서 "여기 워드 12편·한글 5편·PDF 3편이 있습니다" 하고 보여드립니다.
   **볼트 밖이어도 됩니다.**
3. **설교를 어떻게 나누고 계신가요?** → 주일 대예배·수요기도회·새벽기도회처럼
   목사님이 하시는 설교를 여쭤보고, 노트에서 어떻게 나눌지(속성·파일명·폴더) 고르십니다
4. **정리된 설교 노트를 어느 폴더에 넣을까요?** → 볼트를 읽어 후보를 보여드립니다
5. **설교 조각을 어느 폴더에 넣을까요?** → 후보를 보여드립니다
6. **분류(WORD)를 쓰시나요?** → 템플릿 폴더와 900번대 세팅 폴더를 먼저 찾아
   정리해 두신 분류표를 보여드립니다. 설교에 쓰이는 값만 확인하면 됩니다
7. **이렇게 설정할까요?** → 미리보기를 보시고 승인

파일명 규칙은 **여쭤보지 않습니다.** 목사님 설교 파일들을 먼저 읽어 보고
"이렇게 읽었습니다, 맞습니까?" 하고 확인만 받습니다.

### 그다음부터

설교 파일이나 폴더를 알려 주시면 바로 정리합니다.

1. 어떤 노트가 만들어질지 **먼저 보여드립니다** (이 단계에서는 아무것도 생기지 않습니다)
2. 승인하시면 그때 노트를 만듭니다
3. 만든 뒤 링크와 분류가 올바른지 자동으로 검사해 보고합니다

## 만들어지는 것

설교 한 편에서:

- **메인 설교 노트 1개** — 원본 설교문 전체가 그대로 보존되고, 위에 조각별 요약이 붙습니다
- **설교 조각 노트 여러 개** — 논지·해석·예화·적용 단위로 나뉜 작은 메모.
  예화는 제목에 `💡` 가 붙어 한눈에 구분됩니다
- **성경구절 링크** — 설교에 나온 모든 구절이 `[[요3_16]]` 형태로 연결됩니다
- **설교 구분** — 대예배·수요기도회·새벽기도회처럼 목사님이 정한 구분이 노트 속성이나
  파일명·폴더로 나뉩니다
- **분류** — 분류를 쓰시면 frontmatter에 함께 들어갑니다

조각은 나중에 다른 설교를 준비하실 때 검색·재사용됩니다.

## 읽을 수 있는 파일 형식

| 형식 | 준비물 |
|---|---|
| `.txt` · `.md` | 없음 |
| `.hwpx` (한글 표준 문서) | 없음 |
| `.docx` (워드) | pandoc 또는 python-docx — **스킬이 설치해 드립니다** |
| `.pdf` | pdftotext 또는 pypdf — **스킬이 설치해 드립니다** |
| `.hwp` (한글) | pyhwp — **스킬이 설치해 드립니다** |

필요한 도구가 없으면 스킬이 먼저 여쭤보고, 승인하시면 **스킬 전용 폴더에만** 설치합니다
(`~/.pastor-sermon-import/tools/pylibs`). 목사님 컴퓨터의 다른 파이썬 설정은 건드리지
않고, 관리자 권한도 필요하지 않습니다.

설치가 잘 안 되면 이렇게 하셔도 됩니다.

- 한글에서 설교를 열고 **다른 이름으로 저장 → 텍스트 문서(\*.txt)** 또는 **.hwpx**
- 워드에서 **다른 이름으로 저장 → 서식 없는 텍스트(\*.txt)**
- 스캔한 PDF(글자가 아니라 사진인 PDF)는 읽지 못합니다. 원고 파일이 있으면 그것을 주세요.

### 구글 드라이브·원드라이브에 있는 설교

폴더를 알려 주시면 그대로 읽습니다. 두 가지만 확인해 주세요.

- 파일이 **컴퓨터에 내려와 있어야** 합니다 (클라우드에만 있는 파일은 0바이트로 보입니다).
- **구글 문서(`.gdoc`)는 실제 문서가 아니라 링크 한 줄**입니다.
  드라이브에서 `다운로드 → Microsoft Word(.docx)` 로 받아 주세요.

## 준비물

1. **Claude Code**
2. **Python 3** (macOS·대부분의 환경에 이미 있습니다). 윈도우에서 `python3` 명령이
   없다고 하면 `py -3` 로 실행하시면 됩니다 — Claude가 알아서 처리합니다.

## 안심하셔도 되는 것

- 원본 설교 파일은 절대 수정·이동·삭제되지 않습니다.
- 이미 있는 노트는 덮어쓰지 않습니다. 같은 이름이 있으면 멈추고 물어봅니다.
- 같은 제목의 설교 조각이 이미 있으면 그 조각은 그대로 두고 링크만 연결합니다.
- 승인하기 전에는 볼트에 아무 파일도 생기지 않습니다.
- 분류값은 목사님이 쓰시는 목록 안에서만 고릅니다. 새 값을 만들지 않습니다.
- 파일 하나가 실패해도 나머지는 계속 처리됩니다.

## 자주 묻는 질문

**Q. 성경구절 링크가 옵시디언에서 빨갛게 보입니다.**
A. 그 구절의 노트가 아직 없다는 뜻입니다. 정상입니다.
   나중에 구절 노트를 만드시면 자동으로 연결됩니다.

**Q. 설교 조각이 너무 많이/적게 나옵니다.**
A. 설교의 논리 단위대로 나누므로 편마다 3~8개 사이에서 달라집니다.
   개수를 맞추려고 억지로 쪼개거나 합치지 않습니다.

**Q. 더 세밀하게 조절하고 싶습니다.**
A. 같은 묶음에 들어 있는 `pastor-sermon-import`를 쓰시면 됩니다.
   파일명 형식 지정, 같은 제목 조각에 내용 **병합**, 분류 검증 규칙 조절이 가능합니다.
   설정 파일은 호환되므로 지금 설정을 그대로 이어서 쓰실 수 있습니다.

**Q. 설정을 다시 하고 싶습니다.**
A. "설교 정리 설정 다시 할게" 라고 말씀하시면 됩니다.

**Q. 한글 파일(.hwp)이 읽히지 않습니다.**
A. "한글 파일 읽는 도구 설치해줘" 라고 하시면 설치합니다. 그래도 안 되면 한글에서
   **다른 이름으로 저장 → .hwpx** 로 저장해 주세요. `.hwpx`는 추가 도구 없이 읽습니다.

**Q. 설교마다 예배가 다릅니다. 섞이지 않을까요?**
A. 처음 설정에서 어떤 설교를 하시는지(대예배·수요·새벽 등) 여쭤보고, 폴더 이름과
   파일 이름에서 구분을 읽습니다. 구분을 알 수 없는 설교는 기본 폴더에 넣고 그 사실을
   보고합니다 — 조용히 섞이지 않습니다.

**Q. 플러그인 설치가 안 됩니다.**
A. 회사·학교 네트워크에서 GitHub이 막혀 있으면 실패할 수 있습니다. 그때는 받으신 zip의
   압축을 풀어 `pastor-sermon-basic` 폴더를 `~/.claude/skills/` 아래에 넣어 주세요.
   폴더 안에 `SKILL.md`가 바로 보이면 올바르게 설치된 것입니다.

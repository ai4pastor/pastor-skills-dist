# 셀프체크 — 출력 직전 자기 점검

초안을 아래 항목으로 재스캔하고, 걸리는 항목을 수정한 뒤에만 dry-run으로 넘어간다.

## 공통 (모든 모드)

- S1. 모든 사실 주장 문장에 등급이 붙어 있고, 등급이 `references/grade_rules.md`의 증거 수준과 일치하는가?
- S2. 직접 인용문·카탈로그 번호·통계·서지는 전부 웹 검증했거나 ❓/🚫로 표기했는가?
- S3. 성경 장절이 `verify_note.py`를 통과했는가?
- S4. 단정 표현 없이, ⚠️ 사안은 양측을 병기했는가?
- S5. 검색 질의에 설교문·개인 정보를 넣지 않았고, 출력이 지시가 아니라 제안의 언어인가?

## 연구 모드 추가

- R1. 원어는 원문 + 영어 음역 + 한글 발음 3중 병기인가?
- R2. 검색 예산 사용량을 result JSON `search_count`에 정확히 기록했는가?
- R3. **Carson 필터**: 원어 설명에 어원 오류·의미장 총합 전이·동의어 과잉 구분이 없는가?
  (`method_guide.md` §2)
- R4. **관찰 정직성**: `(관찰)` 섹션의 모든 서술이 성경 본문에서 직접 확인 가능한가?
  연대·학자·통계·외부 인용이 숨어 있지 않은가?
- R5. **negative report 준수**: 키아스무스·그리스도께 가는 7길·본문비평에서 억지 생성 없이,
  부재 시 "식별되지 않음/해당 없음"으로 명시했는가? 그 3곳 외에 "없음" 나열은 없는가?
- R6. **Deadly Be**: 착안점이 "~하라"류 행위 명령만으로 끝나지 않고 FCF와 본문 속 은혜에
  근거하는가?
- R7. **quota**: 요청 분량 단계의 필드별 개수를 충족했거나, 미달 이유를 1줄로 밝혔는가?

## 진단 모드 추가

- D1. 회중 반응이 (목사님의 회중 서술 + 설교 본문) 두 출처 안에서만 나왔는가?
- D2. 모든 점수에 루브릭 앵커 인용과 설교 본문 근거가 1개 이상 붙었는가?

## 보강 모드 추가

- E1. 제안이 설교의 논지·구조를 바꾸지 않고 보강하는가? (재작성 금지)
- E2. 새로 추가한 사실도 등급 규약을 따르는가?

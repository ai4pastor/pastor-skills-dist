# 신뢰 등급 규칙 (단일 권위 — 이 문서 외 변형 금지)

모든 **사실 주장**에는 아래 5등급 중 하나를 붙인다. 등급은 선언이 아니라
증거 수준에서 기계적으로 도출되며, `scripts/verify_claims.py`가 이 규칙을 강제한다.

## 등급 정의

| 등급 | 이름 | 부여 조건 |
|---|---|---|
| ✅ | 확인됨 | (a) 결정론 스크립트가 검증(성경 장절, 날짜 계산) **또는** (b) 웹 교차검증에서 서로 독립인 출처 2개 이상 일치 + 그중 1개 이상이 기관 도메인 |
| 🟡 | 개연 | 학계 다수설로 알려져 있고 반증 검색 결과 없음, 또는 웹 출처 1개만 일치. **웹 검증 없이 도달 가능한 최고 등급** |
| ⚠️ | 논쟁중 | 상반된 학계 견해가 확인됨 → **양 진영 병기 의무** (병기 없으면 게이트 실패) |
| ❓ | 불확실 | 근거 부족, 검색 결과 없음, 오프라인 폴백, 추론 단계 |
| 🚫 | 사용금지 | 위조 판정, 검색으로 반박됨, 존재를 확인하지 못한 **구체 식별자**(유물 카탈로그 번호·직접 인용문·논문 서지) → 본문에 사실로 쓸 수 없고, 노트 말미 "주의" 박스에만 기록 |

## 웹 검증 결과에 따른 승격·강등 (재량 없음)

| 검색 결과 | 등급 |
|---|---|
| 독립 2출처 이상 + 기관 도메인 1 이상 일치 | ✅ 승격 |
| 1출처만 일치 (또는 위키류만) | 🟡 상한 |
| 출처 간 불일치·학계 논쟁 확인 | ⚠️ (양측 병기) |
| 존재 확인 실패 — 일반 서술 | ❓ 강등 |
| 존재 확인 실패 — 구체 식별자 | 🚫 강등 |
| 반박 출처 발견 | 🚫 강등 |
| 검색 미실행 (예산 초과·오프라인) | 🟡 상한 + "미검증" 표기 |

- "독립": 같은 원문의 재게시(미러)가 아니고, 도메인이 다를 것.
- "기관 도메인": `data/institutional_domains.json` 목록으로 결정론 판정.
- 위키백과는 단독으로 ✅ 불가. 각주의 원출처 추적 1회는 허용.

## 등급 대상이 아닌 것

- 신학적 해석, 설교 적용 제안, 묵상 → 섹션 제목에 `(해석)` 표시만 하고 등급을 붙이지 않는다.
- 성경 본문 자체의 내용 서술 (장절은 `verify_note.py`가 범위 검사).

## 표기법

- 표기 단위 = 사실 주장 문장 1개. 문장 끝에 이모지 하나만.
  예: `필론(약 BC 20~AD 50)은 로고스 개념을 유대 사상과 결합했다 ✅`
- ⚠️만 짧은 괄호 꼬리표 허용: `⚠️(전기설 BC 15세기 vs 후기설 BC 13세기)`
- 🚫 항목은 본문에 사실로 등장 금지 — 노트 말미 `## 주의 — 사용하지 마십시오` 박스에만.
- `## 검증 요약` 섹션은 직접 쓰지 않는다 — `build_note.py`가 실측값으로 생성한다.
- cys식 표기(`[CONFIRMED]` 등)와 임의 변형은 `verify_note.py`가 차단한다.

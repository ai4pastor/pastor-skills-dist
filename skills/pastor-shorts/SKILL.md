# pastor-shorts — 설교 한 편이 쇼츠가 됩니다

주일 설교 가운데 혼자서도 울림이 있는 1분을 골라, 유튜브 쇼츠로 만들어 드립니다.

- 대본은 목사님 컴퓨터 안에서 만듭니다 (음성 인식 로컬 실행 — 외부 유료 서비스 없음).
- 원본 영상은 **읽기만 하고 절대 수정하지 않습니다.**
- 후보 추천 → 컷 계획 → 시안 미리보기 → 렌더, 단계마다 **미리보기를 보여 드리고 승인을 받은 뒤에만** 다음으로 갑니다.
- 업로드는 목사님이 직접 하십니다. 스킬은 파일과 제목·설명 초안까지만 준비합니다.

명령은 모두 이 스킬 폴더에서 실행한다. 윈도우에서 `python3` 가 없다고 하면 `py -3` 로 바꿔 실행한다.

## Step 0. 도구 점검·설치 (처음 한 번)

```bash
python3 scripts/shorts_env.py          # 설정 홈·나만의 규칙 파일 위치
python3 scripts/setup_shorts.py --check
```

`shorts_rules_exists: true` 면 그 파일(**나만의 규칙**)을 먼저 읽고 이후 모든 단계에 덧입힌다
(교회 이름 표기·설교자 표기·기본 시안·윗줄 문구 등 — 아래 "개인화" 참고).

`--check` 결과의 `needs` 에 따라:

| needs | 할 일 (모두 **여쭤본 뒤에만** 실행) |
|---|---|
| `uv` | 파이썬 환경 관리 도구 uv 설치: `python3 scripts/setup_shorts.py --install-uv` (공식 설치 명령 실행, 관리자 권한 불필요) |
| `venv`·`fonts` | `python3 scripts/setup_shorts.py --install` — 전용 파이썬 3.12 환경 + 아래 패키지 + 글꼴 |

여쭤볼 때 알려 드릴 것: 시스템 파이썬과 시스템 프로그램은 건드리지 않고 설정 홈 안에만 설치한다는 것,
설치 용량(패키지 약 1GB, 첫 대본 때 음성 인식 모델 약 1.5GB 자동 다운로드), 인터넷이 필요하다는 것.

설치되는 것 (모두 자유 라이선스):

| 구성 | 역할 | 비고 |
|---|---|---|
| uv | 스킬 전용 파이썬 3.12 환경 생성 | `~/.local/bin` 에 설치 |
| imageio-ffmpeg | 영상 자르기·합성·인코딩 (ffmpeg 실행 파일 내장) | 시스템 ffmpeg 불필요 |
| mlx-whisper / faster-whisper | 음성 인식 (애플실리콘 맥 / 윈도우·인텔 맥 자동 선택) | 모델은 첫 실행 때 받음 |
| yt-dlp + yt-dlp-ejs + deno | 유튜브 영상 받기 | deno 는 yt-dlp 가 요구하는 JS 실행기 |
| Pillow, numpy | 틀·자막 그리기, 음량 분석 | |
| Pretendard · 나눔명조 · Marcellus | 자막·제목 글꼴 (OFL) | 설정 홈 `shorts/fonts` 에만 저장 |

수동 설치 명령 (Claude 없이 직접 하실 때):

```bash
# macOS
curl -LsSf https://astral.sh/uv/install.sh | sh
python3 scripts/setup_shorts.py --install
```

```powershell
# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
py -3 scripts/setup_shorts.py --install
```

설치가 끝나면 `--check` 결과의 **`python` 경로**를 기억해 두고, 이후 모든 명령을
`"{python}" scripts/sermon_shorts.py …` 로 실행한다 (아래에서 `PY` 로 줄여 쓴다).

## Step 1. 설교 영상 받기

**권리부터 여쭤본다.** "목사님 본인 설교이거나, 교회 채널 영상으로 설교자·미디어 담당의 허락을
받으실 수 있는 영상인가요?" — 아니면 진행하지 않는다. 다른 분 설교라면 **공개 전에 꼭 허락을 받으셔야
한다**고 알려 드린다.

- 유튜브 주소: `PY scripts/sermon_shorts.py fetch "{주소}"` → 작업 폴더가 만들어진다
  (기본: 맥 `~/Movies/설교쇼츠/`, 윈도우 `~/Videos/설교쇼츠/` 아래 `날짜_제목`).
- 영상 파일: `PY scripts/sermon_shorts.py use "{파일}" --title "{설교 제목}"` → 원본은 그 자리에서 읽기만 한다.
- `fetch` 가 실패하면(유튜브 변경·지역 제한 등) 교회 미디어 담당께 원본 파일을 받거나,
  채널 관리자라면 YouTube 스튜디오에서 내려받은 파일로 `use` 를 쓰시라고 안내한다.
  원본 파일이 화질도 더 좋다.

결과 JSON 의 `project` 가 작업 폴더다 (아래에서 `P`).

## Step 2. 대본 만들기

```bash
PY scripts/sermon_shorts.py transcribe --project "P"
```

- 애플실리콘 맥은 30분 설교에 2~3분. 윈도우·인텔 맥은 CPU 로 돌아 훨씬 오래 걸린다 —
  미리 알려 드리고, 급하시면 `--model small`(빠르지만 덜 정확)을 제안한다.
- 같은 영상은 캐시되어 다시 만들지 않는다.
- 끝나면 `P/transcript/sermon.txt`(시간 붙은 대본)를 **처음부터 끝까지 Read 한다.** 후보는 반드시
  전체를 읽고 고른다. 부분만 보고 고르지 않는다.

## Step 3. 쇼츠 후보 추리기 → 표로 보여 드리고 승인

**고르는 기준:**

| 기준 | 내용 |
|---|---|
| 홀로서기 | 앞뒤 맥락 없이 그 구간만 들어도 이해된다 |
| 첫 3초 | 질문·반전·이야기의 시작처럼 붙잡는 첫마디가 있다 |
| 한 메시지 | 하나의 생각이 시작해서 끝난다 (예화 + 적용이 가장 좋다) |
| 길이 | 다듬어서 60초 안팎. 길어도 3분 이하 |
| 소리 | 찬양·배경음악이 섞이지 않은 구간 |

**보류하고 이유를 알려 드릴 것** (목사님이 원하시면 진행하되 주의 표시):

- 실존 인물·성도·가족의 사적인 이야기, 회중이나 어린이의 얼굴·이름이 드러나는 구간
- 맥락 없이 잘리면 설교 의도와 다르게 들릴 수 있는 신학적으로 민감한 주장
- 성경 밖 전승·일화, 통계·역사·학설처럼 **사실 확인이 필요한 내용** — 쓰려면 원문 출처를 확인하고
  "학설 중 하나"처럼 강도를 지킨다. 확인 못 하면 쓰지 않는다.
- 설교 안의 다른 부분을 가리키는 말("아까 읽은", "슬라이드 2번")이 핵심인 구간

후보 표 형식 (3~6개):

| # | 제목(안) | 구간 | 길이 | 첫마디 | 메시지 | 주의 |
|---|---|---|---|---|---|---|

목사님이 고르신 후보만 다음 단계로 간다. 처음이시면 1편으로 시험해 보시길 권한다.

## Step 4. 컷 계획 — 남길 구간 정하기

```bash
PY scripts/sermon_shorts.py pauses --project "P" --from 24:24 --to 25:37 \
   --remove "그랬더니 어르신이 이렇게 대답합니다" --remove "아까 우리가 읽었지만"
```

- 실제 소리(20ms 음량 분석)로 쉼을 찾아 **쉼 안에서만** 자른다 — 단어가 잘리지 않는다.
  Whisper 단어 시간은 1초 가까이 어긋날 수 있어 그대로 자르지 않는다.
- `--remove` 로 뺄 말: 설교 안 다른 곳을 가리키는 말, 대화 사이 이음말("그랬더니 ~가 이렇게 말합니다").
  설교자의 메시지를 이루는 말은 빼지 않는다.
- 0.6초 넘는 쉼은 0.38초로 줄인다 (`--max-pause`·`--keep-pause` 로 조정).
- 결과의 `keep`(남길 구간)·`duration`·`kept_text`(남는 말)를 보고, `phrases` 에 `found: false` 가 있으면
  대본 표기대로 다시 적는다. 남는 말을 목사님께 보여 드리고 승인받는다.

## Step 5. 얼굴 위치 + 디자인 시안 고르기

**① 얼굴 위치** — 구간 중간쯤 프레임을 격자와 함께 뽑아 **Read 로 직접 본다**:

```bash
PY scripts/sermon_shorts.py frame --project "P" --at 25:00 --grid
```

격자 숫자는 원본 픽셀 좌표다. 설교자 얼굴 중심을 `focus: [x, y]` 로 적는다
(창 안에서 얼굴이 위쪽 1/3, 강대상 윗부분까지 담기게 계산된다).

**② clip 파일 쓰기** — `templates/clip_example.json` 을 본보기로 `P/clips/{번호}.json` 을 만든다:

- `keep` — Step 4 결과 그대로 · `focus` — ① 의 좌표 · `output_name` — `01_짧은-제목`
- `meta` — `title`(제목, 짧고 묻거나 붙잡는 말) · `hook`(한 줄 요약) · `scripture`(설교 본문 장절) ·
  `verse`·`verse_ref`(말씀 카드 시안용 구절 — **설교에서 읽은 번역 그대로**, 지어내지 않는다) ·
  `preacher` · `church` · `label_en`·`label_ko`(맨 윗줄 문구). 교회 이름·설교자 표기는 목사님이 알려 주신
  대로만 쓴다.
- `cues` — 자막 줄 목록. **설교자가 한 말 그대로** 쓰고, 음성 인식이 잘못 들은 곳만 고친다
  (말을 다듬거나 바꾸지 않는다). 한 줄 12~20자, 문장·호흡 단위로 끊고, 대화는 “ ” 로 묶는다.
- `highlight` — 강조 색으로 칠할 핵심 낱말 2~4개.

**③ 시안 미리보기** — 목사님 영상 화면으로 네 시안을 그려 보여 드린다:

```bash
PY scripts/sermon_shorts.py preview --clip "P/clips/01.json"
```

`comparison`(시안 비교)과 `comparison_with_youtube_ui`(유튜브 버튼·글씨가 덮인 모습) 두 장을 Read 로 확인한 뒤
목사님 화면에 열어 드린다 (macOS `open`, 윈도우 `start ""`).

| 시안 | 느낌 | 어울리는 자리 |
|---|---|---|
| `1` 클래식 네이비 & 골드 | 격식·안정, 금테 영상 창, 명조 제목 | 교회 채널 기본, 장년 |
| `2` 아이보리 에디토리얼 | 책 한 페이지, 명조 자막, 버건디 강조 | 묵상적인 말씀, 따뜻한 분위기 |
| `3` 시네마틱 다크 | 화면 가득 설교자, 위아래 그라데이션 | 강한 선포·몰입 (원본 화질이 좋을 때) |
| `4` 말씀 카드 | 흐린 배경 위 영상 카드 + 본문 구절 카드 | 본문 말씀을 함께 새기고 싶을 때 |

1·2·4 는 영상을 창 크기로만 키워 화질이 선명하다. 3 은 화면 가득이라 원본 화질이 낮으면 흐려 보인다.
고르기 어려워하시면 `all` 로 넷 다 만들어 비교 영상을 보시게 한다.

## Step 6. 렌더 + 자체 점검

```bash
PY scripts/sermon_shorts.py render --clip "P/clips/01.json" --design 1      # 또는 all
PY scripts/sermon_shorts.py compare --clip "P/clips/01.json"                # all 일 때 4분할 비교 영상
```

- 렌더는 잘라 붙인 구간을 **다시 음성 인식해** 자막 시간을 맞추고, 자막과 실제 말을 대조한다.
- 결과 점검 (실패하면 고친 뒤 다시 렌더):
  - `caption_match_ratio` 0.95 이상, `low_match_cues` 비어 있음
  - `differences` 에 남은 말·빠진 말이 보이면 → `keep` 경계를 조정하거나 자막을 고친다
  - `loudness` 가 약 -14 LUFS
- 결과 영상에서 프레임 몇 장을 `frame --video "{결과.mp4}" --at {초}` 로 뽑아 Read 로 직접 보고
  자막·제목이 틀과 부딪히지 않는지 확인한다.
- 저는 소리를 들을 수 없으므로, 자른 자리의 이음새는 **목사님이 직접 들어 보시라고** 꼭 말씀드린다.

## Step 7. 업로드 준비

1. `P/shorts/{output_name}_업로드정보.txt` 에 제목·설명·해시태그 초안을 쓴다:
   제목(짧게, 100자 이하) · 설명(핵심 두 줄 + 설교 제목·본문·설교자·교회 + 설교 전체 영상 주소가 있으면 링크)
   · 해시태그 3개 이내.
2. 점검: `PY scripts/sermon_shorts.py validate --video "{결과.mp4}" --title "{제목}" --hashtags "#… #…"`
   (찬양이 섞였다면 `--has-music` 을 붙인다)
3. 안내: **YouTube 스튜디오에서 직접 업로드** — 처음엔 '일부 공개'로 올려 확인한 뒤 공개하시길 권한다.
   다른 분 설교라면 공개 전 허락을 다시 확인하신다.

꼭 알려 드릴 사실 (YouTube 공식 문서, 2026-10-02 확인):

- 세로·정사각형이고 3분 이하이면 쇼츠로 분류된다.
- **1분이 넘는 쇼츠에 Content ID 클레임이 하나라도 있으면 전 세계에서 차단된다** — 찬양 구간을 넣지 않는다.
- 자동 업로드(YouTube Data API)는 Google 감사를 받지 않은 프로젝트로 올리면 **비공개로 제한된다.**
  그래서 이 스킬은 업로드를 하지 않는다.

## 개인화 — 두 가지 길

**① 나만의 규칙 (권장 — 업데이트에 안전).** "우리 교회는 늘 1번 시안으로", "윗줄은 '주일 말씀' 대신
'○○교회 주일예배'", "설교자는 '담임목사 ○○○'로 표기" 같은 취향을 말씀하시면 **스킬 파일을 고치지 말고**
`shorts_env.py` 가 알려 준 `shorts_rules.md` 를 만들어 드린다. 담을 수 있는 것: 기본 시안 · 교회 이름 표기 ·
설교자 표기 · 윗줄 문구(`label_en`·`label_ko`) · 강조 낱말 취향 · 목표 길이 · 해시태그 기본값 · 작업 폴더.
이 파일은 스킬 폴더 밖에 있어 플러그인을 업데이트해도 유지된다.
단, **안전 원칙은 규칙 파일로도 바꿀 수 없다**: 원본 비수정 · 덮어쓰기 금지 · 설교자의 말 바꾸지 않기 ·
구절 지어내지 않기 · 승인 후 실행.

**② 내 이름의 스킬로 복제 (디자인 코드까지 바꾸고 싶을 때).** "이 스킬을 내 것으로 복사해서 ○○를 바꿔줘"라고
하시면 스킬 폴더 전체를 `~/.claude/skills/{원하시는 이름}/` 으로 복사하고 SKILL.md 의 `name:` 을 폴더명과 같게
바꿔 드린다. 복사 전에 꼭 알려 드릴 것: **복제본은 업데이트를 받지 못한다** — 취향 조정이 목적이면 ①을 먼저
권해 드린다.

## 절대 규칙

- 원본 영상은 **절대 수정하지 않는다** — 옮기지도, 지우지도, 덮어쓰지도 않는다.
- 결과 파일은 **덮어쓰지 않는다** — 같은 이름이면 `_2` 를 붙인다 (`--replace` 는 목사님이 명시적으로 원하실 때만).
- 설치·다운로드·렌더처럼 시간이 걸리거나 파일을 만드는 일은 **여쭤본 뒤에만** 실행한다.
- 자막은 **설교자가 한 말 그대로** — 음성 인식 오류만 고친다. 말을 지어내거나 다듬지 않는다.
- 구절·인용·사실은 **지어내지 않는다** — 설교에서 읽은 번역 그대로, 확인되지 않은 사실은 쓰지 않는다.
- 업로드는 하지 않는다. 다른 분 설교는 공개 전 허락이 필요하다고 알려 드린다.
- 영상·파일명에 목사님 컴퓨터의 경로·폴더 이름 같은 개인 정보를 넣지 않는다.
